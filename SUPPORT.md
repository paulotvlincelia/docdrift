# Support

DocDrift is a research preview, so support currently comes from the community rather than a formal service-level commitment.

## Where to ask

- **Questions and design discussion:** [GitHub Discussions](https://github.com/paulotvlincelia/docdrift/discussions)
- **Confirmed bugs:** [bug report](https://github.com/paulotvlincelia/docdrift/issues/new?template=bug.yml)
- **Feature proposals:** [feature request](https://github.com/paulotvlincelia/docdrift/issues/new?template=feature.yml)
- **Dataset sources or examples:** [dataset proposal](https://github.com/paulotvlincelia/docdrift/issues/new?template=dataset.yml)
- **Research and evaluation ideas:** [research proposal](https://github.com/paulotvlincelia/docdrift/issues/new?template=research.yml)
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md), never a public issue

Before opening a new topic, search existing issues and Discussions. Include reproducible context while removing secrets, proprietary code, and personal information.
